Ordner, Benennung, Automatik und Konten

TMDB

Kostenloser API-Key von themoviedb.org. Der v3-Key oder das Lese-Token funktionieren beide.

Ordner

Pfade im Container. Für Hardlinks müssen Downloads und Mediathek unter demselben Mount liegen (z. B. /data).

Einsortieren

Hardlinks belegen keinen zusätzlichen Platz. Das Original bleibt im Download-Ordner liegen.

Watch-Ordner

Neue Downloads werden automatisch einsortiert, sobald sie fertig sind und der Treffer sicher genug ist. Unsichere landen im Eingang.

Plex

Nach dem Einsortieren die Bibliothek aktualisieren.

Benachrichtigung

Optionaler Webhook, z. B. für eine Home-Assistant-Automation. Bekommt Anzahl und Dateinamen als JSON.

JDownloader

Damit Nutzer über „＋ Links senden“ Downloads starten können. Am einfachsten mit deinem My.JDownloader-Konto, wie in den Handy-Apps.

Alternative ohne My.JDownloader: überwachter Ordner

In JDownloader die Erweiterung Folder Watch aktivieren und bei FolderWatch: Folders z. B. /output/.mediasort-links eintragen. Hier denselben Ordner so eintragen, wie ihn Mediasort sieht.

Papierkorb

Gelöschte Dateien landen erst im Papierkorb und können wiederhergestellt werden.

Nutzer

Jeder bekommt ein eigenes Konto. Admins dürfen alles, inklusive Einstellungen. Nutzer dürfen sortieren, Dateien ansehen und umbenennen, und löschen, wenn es erlaubt ist.

Benennung

Platzhalter: {title} {year} {tmdbid} {show} {season:2} {episode:2} {eptitle}. Ein / erzeugt einen Ordner. {tmdb-{tmdbid}} hilft Plex bei der Zuordnung.

Benachrichtigung

Bekomme eine Nachricht aufs Handy, sobald ein Film oder eine Folge einsortiert wurde. Du brauchst dafür Home Assistant mit der Handy-App.

  1. Vorlage importieren Vorlage in Home Assistant öffnen
    Öffnet deinen Home Assistant. Dort „Blueprint importieren“ bestätigen und anschließend Automation erstellen.
  2. Diese Webhook-ID in der Vorlage eintragen und dein Handy auswählen
    Als Mediasort-Adresse kannst du eintragen.
  3. Adresse deines Home Assistant
    Die Adresse, unter der dein Home Assistant von außen erreichbar ist. Mit Home Assistant Cloud kannst du stattdessen auch die Webhook-Adresse aus Einstellungen → Home Assistant Cloud → Webhooks einfügen.

Links an JDownloader senden

Links einfügen, auch ganze Nachrichten. Mediasort sucht die Links heraus, JDownloader lädt sie in den Download-Ordner, danach wird automatisch einsortiert.

Tipp: Auf Android kannst du Links auch direkt über Teilen → Mediasort schicken.

Click'n'Load am Handy einrichten

Einmalig ein Lesezeichen anlegen. Danach auf jeder Seite mit Click'n'Load-Knopf das Lesezeichen antippen, Mediasort öffnet sich mit den Links.

iPhone (Safari): 1. Diese Seite als Lesezeichen sichern (Teilen → Lesezeichen hinzufügen), Name Mediasort CNL. 2. Lesezeichen öffnen → Bearbeiten → das Lesezeichen antippen und die Adresse durch den kopierten Code ersetzen. 3. Auf einer Download-Seite: Lesezeichen → Mediasort CNL.

Android (Chrome): 1. Menü ⋮ → ☆ (Lesezeichen), dann Bearbeiten: Name Mediasort CNL, als URL den kopierten Code einfügen. 2. Auf einer Download-Seite in die Adressleiste Mediasort CNL tippen und den Lesezeichen-Vorschlag antippen.
